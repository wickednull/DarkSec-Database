Vector label glyphs
===================

The .pbf files in this directory are SDF glyph ranges for the
"Open Sans Regular" font, used by the MapLibre vector basemap labels.

Source: https://fonts.openmaptiles.org/Open%20Sans%20Regular/
Font: Open Sans, Copyright 2020 The Open Sans Project Authors.
License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)

They are bundled so vector map labels work offline. Do not replace them with
a font you do not have redistribution rights for.
